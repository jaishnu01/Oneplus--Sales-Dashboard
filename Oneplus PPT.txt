2. BEST PROPERTIES & HIGHLIGHTS OF THE PROJECT

Automated Dynamic Line-Item Pricing Math:

Automated discount calculations:
[discount_value] = [unit_price] * [quantity] * [discount]

Net sales dynamic formula:
[sales] = ([unit_price] * [quantity]) - [discount_value]

Profit evaluation pegged to real electronics margins (14% - 26%).

Normalized Data Architecture:

Converted the raw transaction dataset into an official Excel Table
("OnePlusSalesData") to prevent manual cell-range maintenance.

Built-in data typing for dates, currency, and percentages.

Multi-Pivot Visual Architecture:

4 independent Pivot Tables feeding 3 interactive Pivot Charts:

36-Month Timeline Trend (Line Chart)

Regional Sales vs. Profit Comparison (Clustered Column Chart)

Category Revenue Share (Doughnut Chart)

Executive KPI Scorecards (Direct Pivot Cell References)

Centralized Interactive Slicer Network:

Configured unified Report Connections across all Pivot Tables.

A single click on any Slicer (Region, Category) or Date Timeline
dynamically filters every chart and metric card on the dashboard at once.

3. TECHNICAL CHALLENGES ENCOUNTERED & HOW THEY WERE SOLVED

CHALLENGE 1: Excel Timeline Slicer Crash

The Problem:
Clicking "Insert Timeline" triggered the error:
"We can't create a timeline for this report because it doesn't have a field
formatted as date."

Root Cause:
The raw order_date and delivery_date values were imported as string text literals
(e.g., "2019-04-12") rather than Excel date serial numbers.

Solution Engineered:

Applied the =DATEVALUE([@[order_date]]) formula into a designated column.

Formatted the output as "Short Date".

Refreshed the Pivot Cache (Alt + F5), enabling native timeline date indexing.

CHALLENGE 2: Isolated / Non-Responsive Slicers

The Problem:
Inserting a Slicer on one Pivot Chart only updated that individual chart, leaving
the remaining charts and KPI cards static.

Root Cause:
By default, an Excel Slicer only binds to the specific Pivot Table from which it
was generated.

Solution Engineered:

Right-clicked the Slicer border -> Opened "Report Connections...".

Checked all 4 Pivot Tables in the workbook.

Connected the Slicers (Region, Category) and Timeline to the entire dashboard.

CHALLENGE 3: Daily Date Clutter in Pivot Tables

The Problem:
Dragging order_date into Rows populated 1,500 individual daily timestamps rather
than clean monthly aggregates.

Solution Engineered:

Used Pivot Table Date Grouping: Right-clicked a date -> "Group..." -> Selected
strictly "Months" and "Years" while unchecking "Days".

Alternatively generated text period keys via =TEXT([@[order_date]], "mmm yyyy").

4. STEP-BY-STEP REBUILD GUIDE (QUICK REFERENCE)

Step 1: Format dataset as an official Excel Table (Ctrl + T).
Step 2: Confirm order_date and delivery_date are genuine date serials using
=DATEVALUE().
Step 3: Create "Pivot_Calculations" tab and insert 4 Pivot Tables:
- Pivot 1 (KPIs)    : Values -> Sum of sales, Sum of quantity,
Sum of profit, Count of order_id.
- Pivot 2 (Timeline): Rows -> order_date; Values -> Sales & Profit.
- Pivot 3 (Region)  : Rows -> region; Values -> Sales & Profit.
- Pivot 4 (Category): Rows -> category; Values -> Sales.
Step 4: Create Pivot Charts:
- Pivot 2 -> Line Chart.
- Pivot 3 -> Clustered Column Chart.
- Pivot 4 -> Doughnut Chart.
Step 5: Insert Slicers (Region, Category) and Timeline (order_date).
Step 6: Connect Slicers: Right-click Slicer -> Report Connections -> Check All.
Step 7: Cut (Ctrl + X) charts and slicers, paste (Ctrl + V) onto a clean
"Dashboard" tab, and turn off Gridlines (View -> uncheck Gridlines).
